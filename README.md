# CHERI RISC-V Sail model

This repository contains an implementation of the CHERI extensions for the RISCV architecture in [Sail](http://github.com/rems-project/sail).

Originally this was developed with `sail-riscv` as a submodule, but we have moved to including the CHERI code in that repo instead (initially as a branch).

See [sail-riscv](https://github.com/CHERI-Alliance/sail-riscv) for the latest code.
